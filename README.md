# Wabi-Sabi

**Wabi-Sabi** - это инструмент для распознавания текста, вдохновленный японской эстетикой минимализма. Проект сочетает в себе простоту интерфейса и современные нейросетевые технологии.

Название отсылает к философии ваби-саби: красота в несовершенстве, простоте и естественности. Интерфейс выполнен в спокойных тонах с большим количеством свободного пространства.

## Возможности

- Загрузка изображений в форматах JPG, JPEG, PNG.
- Распознавание русского и английского текста.
- Удобное разделение на вкладки: исходник и результат.
- Автоматическое сохранение текста в файл.

## Требования

- Python 3.9+
- pip
